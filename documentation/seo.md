# SEO And Public Data

Chinese public home/search/record/product pages and the public record JSON are indexable. Canonical/hreflang metadata should relate Chinese and English pages without duplicating private routes.

Only the allowlisted public-record contract may appear in sitemap, metadata, previews, or search index. Account state, form tickets, private files, admin paths, internal workspace paths, and unpublished release data are excluded. Dynamic record values are escaped before HTML/metadata output.
