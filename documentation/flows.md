# Critical Flows

| Flow | Actor/precondition | Sequence | Failure/deny |
| --- | --- | --- | --- |
| Chinese search/read | Public visitor | Load static translated UI and public-record contract | No private/admin field can enter index |
| Product navigation | Public visitor | Follow canonical suite URL, with Lab as extraction authority | Site does not emulate account/private product actions |
| Content synchronization | Maintainer | Update translation/shared contract, verify byte/schema compatibility, build | Contract mismatch or nondeterministic index fails CI |

There are no private state changes in this repository.
